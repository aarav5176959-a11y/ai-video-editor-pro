AI Video Editor PRO — Android starter source project
This is source code, NOT a compiled APK.
Includes WebView shell, video picker/playback, speed/filter, trim preview, frame image export, text preview, voice recording and language selector.
AI Baby Cartoon, photo-to-video, actual auto-captions, AI voices and full video export are not active; they require further implementation and potentially external APIs.
To build APK: open folder in Android Studio, allow Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s).
